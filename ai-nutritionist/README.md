# AI 营养师（ai-nutritionist）

一个给 AI 助手用的 Skill（说明书），让它当一个**温和的营养 / 减脂教练**：

- 每顿饭拍张照或说一句话，它负责拆分、估算热量和蛋白质（给区间，标出哪些是估的）
- 有自己的食物库，吃过的不用再查，越用越准
- 可选接入健康 App / 手表 和 体脂秤，自动读数，不用自己报
- 定时主动提醒：早安回顾、饭前建议、查漏记、晚间日报、周报
- 看**周平均**调整，不看单日；缺口温和，饿了就调
- 核心是**无痛**：照常吃正常的饭，只是控制量，不吃难吃的减脂餐

## 为什么做这个

以前也试过自己制造热量缺口，但很难把控：没法直观知道每餐吃了多少、还差多少、该吃什么，得自己查、自己算，懒得算就断了。交给 bot 之后，它会主动告诉我还差多少，吃饭的时候自然就会注意一点。

## 我的情况（仅供参考）

我用 Grok Bot 建了一个叫「营养师」的 bot，按这份 Skill 跑了两周：

- 身高 177 cm
- 早晨空腹体重：75.0 kg（10/16）→ 72.6 kg（10/29），约 −2.4 kg
- 秤测体脂率：19.6% → 18.4%；内脏脂肪等级 8 → 7
- 每天吃 1900–2000 kcal，消耗按手表实测（大多 2400–2800 kcal），不怎么饿
- 运动只是走路，中间出差几天也没断

说明：前期掉得快有一部分是水分；家用体脂秤只看趋势；才两周，样本很小。

## 怎么用

把 `SKILL.md` 放进你所用 AI 助手的 skills 目录（或者直接把内容发给它当作设定），然后跟它说"帮我建档"。

## 注意

不是医学建议。有疾病、在吃药、怀孕/哺乳、未成年或有进食障碍史的，请先咨询医生或注册营养师。不要搞极端节食。
